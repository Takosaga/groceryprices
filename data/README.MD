# Data Directory

This directory contains the data-related files and scripts for the Grocery Prices project. It includes Jupyter notebooks for data processing, a SQLite database, and other related resources.

## Contents

- **`.env`**: Environment variables file for sensitive configurations (e.g., database connection strings).
- **`extracting_nb.ipynb`**: Jupyter notebook for exploring possible methods to extraxt text from PDF brochures.
- **`db_creation.ipynb`**: Jupyter notebook for creating and initializing the SQLite database schema.
- **`grocery.db`**: SQLite database file containing the processed data.
- **`pdfs/`**: Directory containing PDF files of store brochures.
